Reactor Design Exploration

Six visual directions for the reactor core, all driven by the same simulated burn rate / alarm level / agent count. Scratch exploration only — nothing here is wired to real app code.

92,000 tok/min
5 agents

1. Baseline Orb

Current design. Simple radial-gradient sphere; glow radius + pulse speed = burnRate, hue = alarmLevel.
glow ← burnRate · hue ← alarmLevel · pulse-dur ← burnRate

2. Conduit Ring Core

CSS conic-gradient rings replace the canvas housing/conduit draw. Ring rotation speed = burnRate, ring count could scale with agentCount.
ring-speed ← burnRate · hue ← alarmLevel · ring-count ← agentCount

3. Plasma Blob

Gooey SVG-filter merge of drifting blobs. Organic, less mechanical — motion speed = burnRate, turbulence/merge tightness = alarmLevel.
drift-speed ← burnRate · hue ← alarmLevel

4. HUD Gauge Ring

92K
TOK/MIN
Instrument-panel framing: numeric burnRate front and center, arc fill = position in 20K-168K range, color = alarmLevel. Reads at a glance vs. mood-based orb.
arc-fill ← burnRate (0-100%) · hue ← alarmLevel · label ← burnRate value

5. Particle Core

Streaming particles feeding the core, CSS analog of the canvas "warp" mode. Particle count = agentCount, orbit speed = burnRate.
particle-count ← agentCount · orbit-speed ← burnRate · hue ← alarmLevel

6. Minimal Calm Pulse

Low-motion, low-glow alternative for reduced-motion / accessibility contexts. Same data mapping, deliberately understated — a "calm mode" toggle candidate.
ping-interval ← burnRate · hue ← alarmLevel · no continuous animation at nominal-low rate
Params: burnRate (20,000-168,000 tok/min, matches reactorMath.ts clamp range), alarmLevel (nominal/warn/crit), agentCount. Adjust controls above to stress-test all six under the same simulated state.
